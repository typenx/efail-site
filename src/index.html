The game engine built for AI agents

Efail is a deterministic 2D and low-poly 3D game engine built for AI agents. A game is one file of pure functions. The engine owns the window, the clock, input, replays and screenshots, so an agent only writes the game, then checks it headless: state as text, frames as PNGs, the same result on every run.

Why an engine for agents?

Agents making games today spend most of their effort on the layer around the game: choosing a stack, wiring a renderer and input, building ways to see and test what they made, and fighting an editor GUI. Efail makes all of those choices up front, so the agent only writes the game.

  • One file of pure functions

    A game is game.bend: init, step, draw and show. No game loop, no renderer, no input handling.

  • Headless and deterministic

    efail sim runs any number of ticks with scripted keys in milliseconds and prints the state. The same seed and keys always give the same result.

  • Agents can see the game

    efail shot saves any frame as a PNG. efail film puts a whole animation in one labelled grid. The engine writes the pixels itself.

  • Human bugs replay exactly

    efail run records what the player did. efail replay reruns it headless, tick for tick.

  • Proven rules

    Through Bend's laws, a game states facts like “game over waits for Space” and efail check proves them for every input.

  • One page of docs per mode

    AGENTS.md covers 2D and AGENTS3D.md covers 3D. Each fits in a single context window.

How it works: the whole contract

Your game defines a state type and four pure functions. Efail calls step 60 times a second, draws whatever draw returns, and prints show when running headless.

There is no IO, no clock and no randomness except what you derive from the seed. That is what makes every run reproducible, and what lets an agent trust a text line as much as a screenshot.

The API is small: rectangles, circles, text and text-art sprites; keyboard and mouse; seeded random; collision helpers; and retro sounds described as data, which efail sim prints on the tick they start.

The loop an agent works in

Edit, check, simulate, look. Every command is a one-liner whose output is text or a PNG.

CommandWhat it doesOutput an agent reads
efail checkType-checks the game, checks the contract and proves its lawsErrors as text
efail simRuns headless with scripted inputOne show(state) line per sampled tick, plus each sound
efail shotRuns, then saves one framebuild/shot.png
efail filmSaves frames every N ticks in one imagebuild/film.png, each frame labelled with its tick
efail runA human plays in a windowbuild/last.replay
efail replayReruns exactly what the human just did, headlessThe same state lines the human produced
efail webBuilds the game as one self-contained web pagebuild/game.html

Rules you can prove, not just test

Because a game is pure functions in Bend, it can state facts about its own rules as laws, and efail check proves them for every possible input, not only the ones a test happened to try.

The Dodge example proves that its game-over screen stays exactly as it is until Space goes down, and that Space starts a fresh round that keeps the best score.

Quick start

Efail is at v0 and runs on Linux (X11 or XWayland). It needs Bend 2 and clang.

  1. Install Bend, then get Efail and put it on your path.

    curl -fsSL https://bend-lang.com/install.sh | sh
git clone https://github.com/typenx/efail && cd efail
export PATH="$PWD/bin:$PATH"

  2. Create a game and check it headless.

    efail new mygame && cd mygame
efail check
efail sim --ticks 300 --every 60     # state as text
efail shot --ticks 120               # build/shot.png

  3. Point your agent at AGENTS.md in the game folder and tell it what to build. Play the result with efail run (Esc quits).

  4. For 3D, use efail3d the same way.

    efail3d new my3dgame && cd my3dgame
efail3d check
efail3d shot --ticks 120

Frequently asked questions

What is Efail?
Efail is a deterministic 2D and low-poly 3D game engine built for AI agents, written in the Bend programming language. A game is one file, game.bend, made of pure functions (init, step, draw and show). Efail handles the window, the clock, input, replays, screenshots and headless runs.
Why is Efail a good game engine for AI coding agents?
Agents usually spend most of their effort on the layer around a game: choosing a stack, wiring a renderer and input, and finding a way to see and test what they made. Efail makes those choices up front. Everything an agent needs to check is text or a PNG, every run is deterministic, there is no editor GUI, and the whole 2D API fits in one page of docs (AGENTS.md).
How does an AI agent test an Efail game without a screen?
The agent writes a plain-text input file (a tick number followed by the keys held from that tick), then runs efail sim to print the game state as one line of text per sampled tick, efail shot to save a frame as a PNG, or efail film to save a labelled grid of frames in one PNG. The same seed and input always give the same states and the same pixels.
What language are Efail games written in?
Efail games are written in Bend, a Python-shaped, strictly typed functional language. The engine itself is also written in Bend. Game functions are pure: no IO, no clock and no randomness except what is derived from the seed.
Does Efail support 3D games?
Yes. The efail3d command provides a low-poly 3D mode with colored triangle rendering, depth, clipping, transformed primitive meshes, flat lighting, cameras, deterministic gravity, box and sphere collision, raycasts, screenshots and exact replay. Textures, imported models, skeletal animation, shadows and rigid-body joints are outside the first 3D release.
Can Efail games run in a web browser?
Yes, for 2D games. efail web writes build/game.html, one self-contained file that runs the game's own functions compiled to JavaScript, with the same 60 ticks a second, keys, pixels and sounds as the native window. Its Save replay button downloads a replay that efail sim can rerun headless.
What platforms does Efail run on?
Efail is at v0 and runs on Linux (X11 or XWayland). Headless commands such as efail sim and efail shot need no display. 2D games can also be exported to a single web page that runs in any modern browser.
Is Efail free and open source?
Yes. Efail is free and released under the MIT license.
How do you pronounce Efail and what does it mean?
Efail is Welsh for “smithy” and is said EV-ile.
